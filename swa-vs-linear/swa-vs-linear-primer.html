Sliding-window beats linear attention

Two competing "escape the quadratic-cache tax" strategies get compared head-to-head for the first time: Sliding Window Attention (SWA) with a handful of attention sinks — a training-free masking change — against a decade of post-trained Linear Attention methods that spend real compute distilling a transformer into a recurrent kernel approximation. The paper's finding: the training-free option wins on 9 of 11 model families, and by a wide margin on long-context recall, while requiring zero post-training tokens.

arXiv:2608.28444 Jolicoeur-Martineau, Sukthanker, Cameron, Gervais
Live — SWA(w,s) attention mask for a query at position t w=6, s=2, t=12
sink (first s=2 tokens) local window (w−s most recent) masked out

Exactly §03's formula: attend to the first s tokens plus the most recent w−s tokens up to and including t. Total attended set never exceeds w tokens — the KV cache this query needs is bounded regardless of how large t grows.

00 · The reframing

Two lineages have never been compared under the same protocol

Full causal self-attention re-reads a KV cache that grows with every generated token — memory-bandwidth-bound decoding gets slower and hungrier the longer the context. Two independent research lineages attack this:

Linear Attention

Approximate the softmax kernel with a feature map φ so attention reduces to a constant-size recurrent state, updated in O(1) per token regardless of context length. Requires post-training — anywhere from 20M to 100B tokens of distillation, per method — to recover the softmax teacher's behavior through a fundamentally different computational form.

Sliding Window Attention

Keep the exact same softmax computation, just restrict which keys/values a query can see: a fixed-size local window plus a handful of "sink" tokens. No feature-map approximation, no retraining — it's a masking change applied to an already-trained checkpoint. The KV cache is still bounded, this time by construction rather than by approximation.

The paper's core move: put these on the same axis — both promise O(1)-ish inference cost independent of sequence length — and evaluate a training-free SWA configuration directly against a wide field of post-trained linear-attention checkpoints, using identical base models and identical benchmarks. Nobody had run this exact comparison before.

The rest of this page follows the paper's own order: define full attention and linear attention precisely (§01–02), define SWA with sinks precisely (§03–04), catalogue the linear-attention field being compared against (§05), then walk the evaluation protocol and results exactly as reported (§06–10), before a hand-worked example (§11) and the paper's own stated limitations (§12).

01 · §2.1

Baseline: standard causal self-attention

For a sequence of length L, queries/keys/values qt, ki, vi ∈ ℝd, the paper's baseline is the usual causal softmax attention:

§2.1 — full self-attentionverbatim from the paper
xt = ∑i=1t exp(qtki⊤/√d)·vi  /  ∑i=1t exp(qtki⊤/√d),    for t ∈ [1,…,L]

The paper states training complexity as O(D·L²) (quadratic in sequence length, D the model width) and inference cost per newly generated token as O(L) — every step re-reads the full, ever-growing KV cache. Both downstream approaches in this primer exist purely to remove that L-dependence from decoding.

02 · §2.3, Eq. (2)–(3)

Linear attention: replace the softmax kernel with a factorizable one

If exp(qtki⊤) could be written as an inner product φ(qt)φ(ki)⊤ for some feature map φ, the summation could be pulled outside the softmax and accumulated incrementally:

Eq. (2)–(3) — linear attention as a recurrenceverbatim from the paper
exp(qtki⊤) ≈ φ(qt)φ(ki)⊤
xt = φ(qt)st  /  φ(qt)zt,    st = st−1 + φ(kt)⊤vt,    zt = zt−1 + φ(kt)⊤

st is a fixed-size matrix state (outer-product accumulator) and zt a fixed-size normalizer — both updated in place, never re-reading history. The paper reports this as O(1) inference cost with respect to L. As one concrete instance of φ, the paper cites Hedgehog's learnable, dual-sided exponential map:

φ(x) ← ( exp(f(x)), exp(−f(x)) ),    f: ℝD → ℝD/2 a learned linear projection

Every linear-attention method in this comparison picks a different φ (or a different way to train one) — that choice, and how much post-training it costs, is what §05 catalogues.

03 · §2.2

SWA(w, s): the same softmax, over a bounded, fixed index set

Sliding Window Attention keeps the exact softmax kernel from §01 but restricts the sum to a local window of the w most recent positions:

§2.2 — sliding window attentionverbatim from the paper
xt = ∑i=max(1,t−w+1)t exp(qtki⊤/√d)·vi  /  ∑i=max(1,t−w+1)t exp(qtki⊤/√d)

Used alone, a pure local window loses everything more than w tokens back — including, notably, the very first tokens of the sequence, which empirically anchor attention distributions in trained transformers (the "attention sink" phenomenon; §04 covers why). SWA with sinks fixes this by reserving s of the w attended slots for the first s tokens, unconditionally, and spending the remaining w−s slots on the local window:

§2.2 — SWA(w, s), notation used throughout the paperverbatim from the paper

SWA(w, s): attend to the first s tokens (fixed at s=4 throughout the paper) in addition to the remaining w−s sliding-window slots ending at t.

Written as an index set (this primer's notation, matching the paper's description exactly):

ℐ(t) = {1, …, s} ∪ {max(s+1, t−(w−s)+1), …, t},    |ℐ(t)| ≤ w

When t < w, the sink range and the local-window range overlap and the union simply has fewer than w distinct members — the formula degrades gracefully to ordinary causal attention at the very start of the sequence, with no separate case needed. The live mask visualization at the top of this page renders ℐ(t) exactly, for any t and w you choose.

04 · §2.2, complexity

Why sinks, and what SWA actually costs

Prior work (StreamingLLM) observed that trained transformers dump a disproportionate share of attention mass onto the first few tokens of a sequence, independent of their content — softmax needs somewhere to send probability mass for queries with no strongly relevant key, and the first tokens become that release valve during training. Drop them from a pure sliding window and perplexity spikes as soon as they exit the window, even though those tokens carry little semantic content themselves. Reserving s=4 permanent slots for them costs almost nothing (4 out of a w≥64 budget) and removes the spike.

Because |ℐ(t)| ≤ w for every t, SWA's per-token inference cost and KV-cache footprint are both bounded by w — independent of L, same qualitative win as linear attention's O(1), but reached by truncating the exact softmax rather than approximating it with a different kernel. That distinction is the paper's whole thesis: truncation error from a bounded window turns out to hurt less, empirically, than kernel-approximation error from linearization — and truncation requires no post-training to deploy.

S-NIAH asks the model to retrieve one fact planted at a specific depth in a long, distracting context — a direct stress test of exactly what a bounded window or a bounded recurrent state is supposed to be bad at, and exactly where the paper's comparison is most informative:

Larger windows help substantially: SWA(512,4) "substantially outperforms" SWA(128,4) at 4K context in the paper's own ablation — the needle is more likely to fall inside a bigger window, unsurprisingly, but the linear-attention baselines don't get an equivalent lever, since their whole appeal is a state size that does not grow with an effective "window."

11 · Hand-verifiable example

One query, six tokens, SWA(4, 1) vs. full attention

constructed for this primer, arithmetic checked by hand

Take a query at t=6 over T=6 tokens, scalar values v = [10, 1, 2, 8, 4, 9], and precomputed logits zi = q6ki⊤/√d = [1.0, 0.2, 0.1, 1.5, 0.5, 2.0].

Full attention — all 6 positions

exp(z) = [2.71828, 1.22140, 1.10517, 4.48169, 1.64872, 7.38906], sum = 18.56432.

weights = [0.14641, 0.06579, 0.05953, 0.24140, 0.08880, 0.39807]
x6full = ∑ weight·v = 1.4641+0.0658+0.1191+1.9312+0.3552+3.5826 ≈ 7.518
SWA(4, 1) — index set ℐ(6) = {1} ∪ {4,5,6} = {1,4,5,6}

Sink s=1 keeps token 1; window w−s=3 keeps the 3 most recent tokens ending at t=6, i.e. {4,5,6}. Tokens 2 and 3 are masked out entirely — they contribute 0.06579+0.05953=0.1253 of the full-attention probability mass, which softmax now redistributes among the 4 survivors.

exp(z) restricted to {1,4,5,6} = [2.71828, 4.48169, 1.64872, 7.38906], sum = 16.23775
weights = [0.16744, 0.27604, 0.10154, 0.45514]   (for tokens 1, 4, 5, 6 respectively)
x6SWA = 1.6744+2.2083+0.4062+4.0963 ≈ 8.385

Dropping tokens 2 and 3 moves the output from 7.518 to 8.385 — a real, nonzero distortion from masking, exactly as the paper's Eq. in §03 would predict (renormalizing over a strict subset of positions). The paper's empirical claim is not that this distortion is zero; it's that this kind of truncation distortion, in aggregate, costs less downstream accuracy than the distortion a linear-attention kernel approximation introduces at comparable post-training budgets — which is exactly what §07–09's tables measure.

12 · §5, as stated in the paper

What the paper itself says it doesn't cover

  • Training-free only: the paper explicitly notes "post-training can further improve the performance of SWA" but does not investigate it — the comparison is zero-shot-SWA vs. post-trained-linear, not post-trained-vs-post-trained.
  • No hybrid architectures: "We did not consider hybrid models with some tokens or entire layers using full-attention (FA)" — despite hybrid SWA/full-attention layouts being common in deployed models.
  • Scale: the analysis stops at 70B and standard benchmarks; the paper flags extension to "extremely large models and complex metrics, such as agentic tasks" as future work.
  • No multimodal evaluation: no coverage of multimodal LLMs or video generation models.
  • No budget-matched scaling laws: the paper does not sweep linear-attention post-training token budgets to characterize where (if anywhere) more post-training compute closes the gap to SWA.

Areas this primer would flag for improvement

The following is this primer's own commentary on the paper — not the paper's text, and not a criticism of the arithmetic or transcription above, all of which is verified against the source. These are methodological gaps worth keeping in mind before treating "SWA beats linear attention" as a closed question.

  1. uneven compute budgets The post-training token budgets compared range from 20M (Liger-GLA) to 100B (SUPRA) — a 5000x spread — yet SWA is compared against all of them with a single zero-token configuration. SWA still wins in most cases, which is the paper's real finding, but the comparison doesn't establish where on that 20M–100B spectrum a linear method would need to sit to close the gap; a budget-matched sweep (flagged as future work in §5 anyway) would make the "wins despite/because of zero training cost" claim sharper.
  2. sink count never ablated Window size w is swept across four values ({64,128,256,512}), but sink count s is held fixed at 4 throughout every experiment. Given how load-bearing the sink mechanism is for avoiding early-token loss (§04), a small ablation over s ∈ {0,1,2,4,8} would clarify how much of SWA's advantage comes from the window vs. from the sinks specifically — especially since s=0 reduces to a pure local window, whose failure mode the paper only describes qualitatively.
  3. hybrid layouts excluded by design, but they're the deployed norm Several widely-used production models (e.g. Gemma's interleaved local/global attention, GPT-OSS-style layouts) already mix SWA layers with periodic full-attention layers specifically to recover long-range recall while keeping most layers cheap. The paper explicitly scopes this out (§5), which is a reasonable scoping decision for a first head-to-head, but it means the reported S-NIAH/BABILong numbers describe pure-SWA's ceiling, not the hybrid configurations most likely to actually be deployed — a comparison against hybrid SWA and against hybrid linear-attention stacks (linear layers + periodic full attention) would be the natural follow-up.
  4. O(1) for linear attention undersells its real per-step cost The paper (and this primer, following it) states linear attention's inference cost as O(1) in L, which is correct with respect to sequence length — but the state st is a d×d (or feature-dim-squared) matrix, so the actual per-step cost scales with the feature dimension, and larger feature maps (needed for better softmax approximation) trade solved sequence-length-dependence for a fixed but nontrivial quadratic-in-d cost. Reporting a wall-clock-normalized comparison against SWA's O(w·d) at matched accuracy, rather than just an asymptotic order, would make the speed claim in §10 more directly comparable.
  5. small-scale speed benchmark for a large-scale claim §4.3's throughput/memory numbers come from a 4-layer, d=64, batch-1 model — useful for isolating the mechanism, but memory-bandwidth bottlenecks, kernel fusion opportunities, and batching effects all shift meaningfully at production scale (multi-billion-parameter models, batch > 1, tensor/pipeline parallelism). The paper's own accuracy results span up to 70B; the speed results don't, and a reader shouldn't assume the two curves extrapolate identically.
