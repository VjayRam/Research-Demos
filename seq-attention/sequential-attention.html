00 / Setup

Why feature selection is hard

Choosing the best k out of d features is combinatorial — and in a neural network, "best" depends on who else is already selected.

You have a dataset with d features and a budget: keep only k of them, because the rest cost latency, storage, or a licensing fee per column at inference time. The naive way to find the best subset is to try every combination — C(d,k) of them — train a model on each, and keep the winner. For d = 100, k = 10, that's roughly 1.7 × 1013 models. Nobody is training that many models.

The second problem is subtler than the combinatorics: features interact. A feature can look useless on its own and become essential once paired with another (think of two GPS coordinates — either alone is nearly meaningless; together they pinpoint a location). Neural networks make this worse, because the "usefulness" of a feature is filtered through several layers of non-linear transformations before it affects the loss. Scoring features one-by-one, independently, misses exactly the interactions the network is best at exploiting.

→

The move Sequential Attention makes: instead of scoring all d features at once and freezing that ranking (as most one-shot importance methods do), it selects features one at a time, and re-scores everyone who's left in the context of who's already been picked. Each pick answers "what's the best next feature, given the team I've already assembled?" — not "what's the best feature in isolation?"

01 / Mechanism

The attention mask

One learnable vector of logits, one softmax, one Hadamard product with the input. That's the entire architectural change.

Sequential Attention doesn't bolt a new sub-network onto your model. It adds exactly d extra trainable numbers — a logit wi per feature — and multiplies each input feature by a softmax-normalized version of its logit before anything else happens. Formally, given the set of already-selected features S and its complement S̄ (still up for grabs):

softmax attention mask
softmaxi(w, S̄)  =  { 1       if i ∈ S exp(wi) / Σj∈S̄ exp(wj) if i ∈ S̄
masked input:  X ∘ W,  where  W = 1n · softmax(w, S̄)⊤

Read the two cases separately, because they're doing different jobs. Already-selected features pass through untouched (weight = 1) — once a feature has earned its spot, the mask gets out of its way. Unselected features get softmax-normalized against each other — they're all fighting over the "how much attention is left to give" budget, so raising one logit necessarily shrinks the others' effective weight. That competitive normalization is what makes the logits behave like a proper importance ranking rather than d independent scalars.

The whole assembly then just gets multiplied element-wise (∘, the Hadamard product) into the input before it hits the rest of the network — one line of code, trained with ordinary backprop, no separate importance-estimation pass required.

02 / Procedure

The greedy loop

k rounds. Each round: train with the current mask, read off the highest logit among what's left, lock it in.

Put the mask inside a training loop and the algorithm writes itself. This is Algorithm 1 from the paper, in full:

Algorithm 1 — Sequential Attention
input: dataset X ∈ ℝⁿˣᵈ, labels y, model f, loss ℓ, budget k
  1. S ← ∅  // no features selected yet
  2. for t = 1 … k do
    (θ*, w*) ← argminθ,w ℓ( f(X ∘ W ; θ), y )  // train model + mask jointly
      where W = 1n softmax(w, S̄)⊤
    i* ← argmaxi∉S w*i  // read off the winning logit
    S ← S ∪ {i*}  // lock it in, permanently
  3. return S

Three things are worth noticing here. First, the objective being minimized, ℓ(f(X∘W;θ), y), is nothing exotic — it's the model's ordinary training loss, just fed masked inputs. There's no separate "importance loss" or regularizer to tune. Second, the argmax is over w*, the raw logits, not the post-softmax weights — the softmax's job was only to shape gradients during training; the actual selection rule is "biggest logit wins." Third, and most important: because S only grows and never shrinks, round t's training run already has rounds 1…t−1's picks baked into the mask as fixed, weight-1 passthroughs. The model that scores round 4's candidates has genuinely seen what rounds 1–3 look like in combination — that's where the "marginal gain given context" property comes from, for free, with no explicit marginal-gain computation.

04 / Efficiency

Training one model, not k

The straightforward reading of Algorithm 1 trains k separate models. The paper's implementation trains one.

Algorithm 1's outer loop, read literally, calls for k full training runs — one to pick each feature. In practice the paper partitions a single model's training epochs into k contiguous phases and selects one feature at the boundary of each phase, resetting only the attention logits (not the network's weights) between phases:

This works because the network weights θ don't need to restart from scratch every time a new feature joins S — they just keep adapting. Only the competition among the *remaining* logits needs a clean slate, since the softmax normalization changes shape every time S̄ shrinks by one. The result: the entire selection procedure costs about as much as training the target model once, plus d extra floats.

05 / Theory

Why this is Orthogonal Matching Pursuit

Strip the neural network down to linear regression, and Sequential Attention's selections become mathematically identical to a 1993 sparse-recovery algorithm.

Theorem 1.1

For linear regression, regularized-linear Sequential Attention is equivalent to Orthogonal Matching Pursuit. Every provable guarantee OMP has — recovery under restricted-isometry-style conditions, bounds tied to the sparse condition number of X — transfers directly to Sequential Attention's selections in the linear case.

The mechanism behind the middle step is worth sitting with: the Hadamard product overparameterization s(w) ∘ θ — writing one coefficient as a product of two learned factors instead of directly — is what turns an ℓ2 penalty on both factors into an effective ℓ1 penalty on their product. This is the same "implicit regularization via overparameterization" phenomenon studied elsewhere in deep learning theory; here it's precisely what makes softmax-style attention masks behave like sparsity-inducing LASSO penalties, without ever writing an ℓ1 term into the loss.

And the last arrow — Sequential LASSO's selection rule matching OMP's residual-correlation rule — is exactly the quantity the simulator in §03 computed at every round: |Xᵢᵀ r| for the current residual r. That's not a coincidence built for this page; it's the paper's actual proof target.

06 / Ablation

The softmax isn't the magic part

Swap the softmax for other overparameterizations and performance barely moves — which tells you where the power actually comes from.

It's tempting to credit softmax attention specifically — after all, "attention" is in the name. The paper's ablation pushes back on that: it compares the softmax mask against other ways of overparameterizing each coefficient as a product of two learned factors — an absolute-value (ℓ1-style) mask, a squared (ℓ2-style) mask, and a normalized variant — and finds they all reach nearly identical downstream accuracy.

The conclusion the authors draw — and the reason §05's proof bothers to isolate the Hadamard product rather than the softmax — is that the overparameterized product structure is the active ingredient, not the specific normalization. Softmax is a convenient, differentiable choice that happens to also give an interpretable "attention weight" story, but the sparsity-inducing effect comes from writing each coefficient as a product of two co-trained factors.

08 / Extension

Beyond single features: SequentialAttention++

The same greedy-attention idea, applied to entire blocks of weights instead of input columns.

A follow-up line of work, SequentialAttention++, applies the identical playbook — sequential, attention-scored, greedy selection — to block sparsification: instead of picking which input feature to keep, it picks which blocks of a weight matrix to keep, combining the sequential-attention selection rule with group-lasso-style structured penalties so that entire blocks can be zeroed out together. Because whole contiguous blocks disappear (rather than scattered individual weights), the resulting sparsity pattern is the kind GPUs and TPUs can actually exploit for real speedups — unlike unstructured pruning, which is sparse on paper but often just as slow in practice. Reported gains include meaningful model-compression improvements on ImageNet-scale classification without sacrificing accuracy.

◆

The throughline across both papers: attention weights, trained sequentially with a growing "already committed" set, are a cheap and theoretically-grounded proxy for marginal value — whether the thing being valued is an input feature or a block of a weight matrix.

09 / Cheat sheet

The whole algorithm in six cards

The problem

Pick k of d features under combinatorial + interaction constraints; C(d,k) exhaustive search is infeasible.

The mechanism

+d logits, one softmax mask, Hadamard product with the input. Selected features pass through at weight 1.

The loop

k rounds: train, take argmax of the raw logits among unselected features, freeze it into S forever.

The efficiency trick

One model, k training phases, reset only the attention logits between phases — not k separate models.

The theory

Linear case: Sequential Attention = Sequential LASSO = Orthogonal Matching Pursuit. Inherits OMP's guarantees.

The real ingredient

Not softmax specifically — the Hadamard-product overparameterization is what induces implicit sparsity.
